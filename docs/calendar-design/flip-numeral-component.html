The setting mechanism

Typography follows whether a date is being read or set. A date on display stays quiet, typed, minimal. A date being set becomes a machine: split-flap cards that tick one value at a time — discrete, mechanical, no momentum. Day roll-over carries the month, like a real flip clock at midnight.

Pointer
Rest on a card and scroll — each notch is one tick.
Keyboard
Tab to a card; ↑ / ↓ tick the value. Type digits on the day or year card to jump exactly — “2”, “7” lands on 27.
Touch
Hold and drag vertically. The value only moves while your finger moves — a flick does nothing, on purpose.
Exact entry
TYPE reveals a native date field for fast, precise input. Nothing here is reachable only by gesture.

Accessibility contract: each card is a role="spinbutton" with aria-valuenow/-valuetext/-min/-max, focusable at 44px+; arrows and typed digits work everywhere the wheel or a drag works; “reduce motion” swaps the flip animation for an instant change. Scoped to Calendar only in this pass — the component is one self-contained module (js/widgets/flipdate.js) with a mount(el, {value, onCommit}) shape, so other date fields can adopt it later without a rewrite.
