# Prairie Village — Birthday Build

## Phase 2: Smallest Runnable Vertical Slice

This repository contains the first runnable Prairie Village build.

The current version intentionally includes only:

- A small top-down canvas map
- Mike
- Four-direction movement
- Arrow-key controls
- WASD controls
- Henry
- Delayed following behavior
- Map-boundary collision
- Letter-grid sprite rendering
- Crisp, unsmoothed pixels

It does not yet include houses, trees, rabbits, farming, crafting,
mobile controls, saving, audio, weather, or PWA installation.
